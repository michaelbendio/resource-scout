# Mesa editorial handover — September 9, 2026

These portable snapshots preserve the inputs and outcome of the initial frontier-editor preparation for Mesa. Current source code and guidance live on **`v2.0`**; `main` retains the established Scout line.

- **[scout-editor-handover.zip](scout-editor-handover.zip)** — Michael's checklist, the editor brief, report/decision formats, approved writing example, technical background, and the original 460-resource research in JSON, resource-package ZIP and matching complete Scout HTML. The ZIP is the authoritative input; the HTML is a fresh rendering of that same saved data, without later browser-local edits.
- **[astra-editor-reference.zip](astra-editor-reference.zip)** — Astra's common-format report, a decision for every original ID, proposed improvements, the 268-resource editable autoMesa, its full draft package, comparisons and validation records. It is AI editorial preparation for human curation, not a phone-verified office release.
- **[packet-manifest.json](packet-manifest.json)** — packet hashes, sizes and source counts.

For an independent editorial comparison, supply the main packet first and withhold the Astra reference until the editor saves its initial decisions. For an informed revision of the 268-resource collection, supply both and say so. Do not use either dated snapshot as a substitute for a future office's current data.

Download the ZIP through GitHub's **Download raw file** control on its file page, or obtain it from a repository checkout. Unzip and open `START-HERE.html` or `START-HERE.md`. Both packets include internal file/hash inventories. No server or Scout database is required to read them.

The original research had 460 entries. The editorial result retained 268 source identities, folded in 41 overlapping entries, reserved 123 and excluded 28: **309 selected source entries became 268 final resources**. Groups and types were reconciled with the retained collection. Source-to-destination mappings and original records remain available in the reference packet.

The large run databases, raw browser conversations and unrelated local output directories are not committed in this archive. Source references and resource evidence are supplied in the packets; request specific additional raw research if needed. No automatic learning or integrated model-independent editor was implemented by preparing these documents.
