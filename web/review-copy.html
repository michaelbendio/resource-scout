Save work

  • The Curator saves automatically in this browser when browser storage is available. Choose Save work regularly to download a portable JSON work file containing every note, checklist item, resource edit, package record, and PDF you add.
  • Keep the JSON with this Curator HTML. To continue in another browser or on another device, open the HTML and choose Open saved work. When your review is finished, send the JSON back to the person who provided the Curator. The HTML does not update itself.

Save a resource package

This creates a ZIP containing only resources marked Ready for package, then archives those candidates from the active queue while preserving their work and package history. Save work separately for a portable backup of all curation.
