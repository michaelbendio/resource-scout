## Learning test

Six saved Mesa Employment cases were tested with the same Claude model/settings in separate fresh incognito contexts. The candidate added a short method distinguishing barriers before entry from useful help during a program. Criteria were saved before dispatch; supporting examples were outside the test set.

Both answers made **the same six decisions** and preserved the main access restrictions. The candidate produced **38 follow-up questions versus 24**, and **1,689 words versus 1,371**. That is potential added curator work, not measured human time.

There was no selection gain. The recorded rubric rates the candidate slightly worse: it called a listed phone “working” without a call; both answers called an address verified despite this being saved-case interpretation. This narrow wording regression in one pair does not establish general model inferiority. **The lesson remains inactive.**

This output-format correction does not activate the experimental lesson or impose a fixed resource-text cap. Original assignments retain their sealed instructions.

Checkpoint phases took milliseconds. The visible delay was external generation and UI handling, so further storage tuning is unjustified here. Nested phase totals are not wall time. Astra's shared effort was unallocated (zero fields are explicitly qualified), Claude's minutes are estimates, and cost is unknown. No provider-speed comparison or office-wide ETA is supported.
