## What differed

**City Hope:** Both correctly direct clothing patrons to Gilbert and retain the ID, visit-frequency and capacity conditions. The candidate adds a curator question about Mesa because the homepage is broader. My judgment is that the explicit location notice already supports the conservative referral; **the extra question creates work without improving it**. This is a useful counterexample to treating every difference between an overview and a detailed page as an unresolved contradiction. [Location-specific instructions](https://www.cityhopeaz.org/centers), [homepage](https://www.cityhopeaz.org/).

**Paz de Cristo:** Both preserve the adult-only closet and its practical starting point. Both also keep the genuinely conflicting voucher wording visible instead of promising vouchers. The coordinator verified the material claims in these three drafts against six pages. ## What the machinery actually exercised

This was real research through the new architecture: measured evidence → inactive policy proposal → two sealed live trial arms → four passes, synthesis, freeze and reconciliation in each → captured results → recorded evaluation. The two contexts stayed separate. Actual returned web evidence, source failures, original answers and timing records were preserved. No synthetic research responses were used.

The preflight isolation fix prevented previous-run lookup from showing one arm the other's results. One baseline submission needed a format-only retry because prose guidance mentioned a field absent from the exact schema. That failed delivery remains saved. Initial stage-time estimates were imprecise; corrected timestamp-based totals are recorded separately, without rewriting accepted receipts.

Both runs respected the source ceilings, reached a research cap, and retained unresolved gaps. The candidate's attempted PDF reads did not establish the PDF-based coverage it sought. The activation blockers reflect limits and unresolved gaps: neither run was late or missing a required stage. Completing a bounded assignment does not establish exhaustive discovery.

Measured web-tool latency totaled only 16.0 and 13.8 seconds. The remaining elapsed time combines model work, reading/writing, local transport and coordination; this test does not separate them or justify another performance rewrite.

## What I recommend next

**Do not add this broad instruction or repeat it hoping for a positive result.** Preserve the finding that the existing guidance already produced the important intake details here. The candidate's extra curator question is a possible failure pattern to watch, not a new rule ready for activation.

All five numbered increments remain implemented. The next learning opportunity should come from a recurring, consequential problem in ordinary maintenance or curator feedback. If one appears, use a small matched-case test that isolates it. This one pair supports keeping the current policy; it does not prove the proposed instruction could never help elsewhere.
