found fourteen earlier Type IDs absent from the proposed full catalog. This was
an export compatibility omission, not a missing-resource finding.

`type_mesa_housing_housing-legal`. Its revised description does not establish a
different navigation concept. The provisional replacement ID is removed from
the full payload and all its assignments.

formula within infant/young-child nutrition, ADA paratransit within accessible

`taxonomy-transition.json`. Two pairs consolidate into broader concepts:
affordable housing/vouchers, and mailing address/document storage. Resource text
retains the narrower actual services; matching a broad Type never establishes
that every service named in its definition is offered by a particular resource.

the broader Scout taxonomy as a proposal. Import must not delete old office Types
or silently retag human records. This supplement records reviewed transitions;
it is not an automatic taxonomy-migration instruction or a resource-ID change.

evidence. A new reviewed bundle, static attestation and delivery directory bind
