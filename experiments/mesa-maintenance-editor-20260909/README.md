# Mesa maintenance and editorial pilot — September 9, 2026

One operator-led cycle on twelve purposively selected records from the earlier 268-resource Mesa editorial draft. Four focal records each in Clothing, Employment and Housing; actual memberships overlap. The source is an AI draft, not a phone-vetted package. No later human resolutions were found in the three saved Mesa ZIPs checked; browser-local changes were not inspected or claimed captured.

`plan.json` was written before research. `primary-findings.json` and its timestamp/hash freeze precede the targeted pass. `targeted-findings.json` distinguishes new detail, corroboration, continuing conflict and failed retrieval. The coordinator worked in one context and saw historical editorial decisions. No blind test, additional model, provider call or whole-office research was run.

This used Scout's package reader/writer, question-preservation functions, common HTML renderer, editorial evidence import, explicit package comparison and ordinary feedback queue. It did **not** execute the sampled multi-provider maintenance scheduler or the new-discovery editor orchestration. No operational assignment completion was fabricated. Learning evidence was imported into a separate pilot database; no manifest or production resource was changed.

The original twelve records and all package assets are preserved in `source-package.zip`. `prior-editorial-context.json` preserves the related earlier decisions with their original run identity. `editorial-decisions.json` accounts for every selected ID and exact changed fields. `draft-resources.json` and the draft ZIP are partial, reviewable output. Existing question IDs, explanations, answers and histories remain exact. Two new questions remain open.

Outcome: twelve retained, three text edits, no forced consolidation. The voucher office and deposit program retain distinct purposes and application routes despite matching contact details. The two overlapping deposit eligibility questions can be covered by one provider inquiry, but their separate histories were preserved.

No method was proposed: the cycle did not supply three independent mistakes supporting one method. Reconfirmed conflicts are useful counterevidence, not successful corrections to inflate a lesson's support. The coordinator's initial thought of replacing deposit eligibility with the public-page number was caught before editing and is recorded as one near-miss. A fixed-source test was therefore not triggered.

## Reproduce and verify

From the repository root:

```sh
PYTHONPATH=. python3 experiments/mesa-maintenance-editor-20260909/verify.py
```

Verification uses saved data and temporary databases; no network or model calls. `build.py` documents construction and can recreate the operator output in its isolated output directory. Its original ZIP and timestamp are preserved across replay. Do not replace a production office with this partial draft or treat missing resources as deletions.

The readable results are in [the pilot report](../../docs/scout-mesa-maintenance-editor-results.md). Instrumentation covers actual coordinator tool calls and phase elapsed time, not independently measured model computation or curator time. Source attempts and search queries are separate; PDF page counts are not interchangeable with document requests. Some resources received more than the planned two source attempts while staying within the total primary request allowance; that deviation is preserved in the primary findings.
